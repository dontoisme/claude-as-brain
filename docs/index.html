claude-as-brain

A personal knowledge system where Claude Code is the retrieval layer.

No app to install. No plugins. No proprietary format. A folder of markdown files, an optional task database, and a set of commands that make Claude genuinely good at operating them.

Search can't do this

Not full-text search, not graph view, not a Dataview query. Answering that question requires reading several notes, noticing two of them quietly disagree with a decision, and saying so — that's synthesis, not retrieval, and it's the whole point of putting a model in the loop instead of an index.

But the files underneath stay ordinary. Full PARA + MOC structure, YAML frontmatter, [[wikilinks]], plain markdown throughout. Install Obsidian tomorrow and the vault lights up with graph view and backlinks — nothing to migrate. Lose every tool and you still have a folder of readable notes. That's the actual constraint: markdown is the source of truth, and everything else is an accelerator that could vanish without costing you any knowledge.

Three memory layers

Most systems have one layer and bolt tasks onto the side. This has three, with a clear rule for what goes where:

LayerHoldsComes back via
NotesProse, reasoning, meeting records, decisionsClaude reads and synthesizes
Beads issuesCommitments — owner, state, dependenciesbd ready, bd stale, bd graph
Beads memoriesDurable one-line factsAuto-injected into every session

Want to read it later → note. Need to do it → bead. Should Claude just know it → memory.

Start here

Three commands. Everything else can wait until you want it.

git clone https://github.com/dontoisme/claude-as-brain.git my-brain
cd my-brain
claude

Then, inside Claude Code:

  1. /thread annual pricing — see the worked example answer the question above, before you change anything
  2. /install — turn the distribution into your own vault
  3. /capture, /ask, /daily-note — the only three commands you need on day one
